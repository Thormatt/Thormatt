### Thor Matthiasson

I build LLM systems and measure whether they work. Most of my work sits between models: getting several to deliberate, checking what they claim against evidence, and replacing conversation with computation where that is more reliable.

#### Selected work

**[Computed Targets and the Middleman Protocol](https://github.com/Thormatt/llm-negotiation)** · paper, code and data\
LLM negotiators do worse when given strategic advice in text, and better when given a computed numeric target: outcome variance falls 2.3–9.9×. Replacing the conversation with a neutral protocol lifts Pareto efficiency from 79% to 91–96% and removes the frontier-model advantage. Eight models from five labs; every headline table recomputes from the released game logs.

**[Plurality](https://github.com/Thormatt/plurality-ai-mcp)** · MCP server and web app · Apache-2.0\
Ask a panel of models instead of one. Eight deliberation methods (debate, red team, peer review, forecast and more) return a decision memo that keeps the disagreements and the full transcript. Runs as a personal MCP server in Claude, Codex or any MCP host.

**[orc](https://github.com/Thormatt/orc)** · verification runtime\
Checks AI output claim by claim against evidence, with chunk-level citations, deterministic replay and audit bundles. F1 0.864 on a 504-item HaluBench subsample using an off-the-shelf Claude Sonnet 4.6 call, no fine-tuning.

**[MoGRU](https://github.com/Thormatt/mogru)** · negative result\
A momentum-gated recurrent unit, published with the cases where second-order dynamics help and the ones where they don't.
